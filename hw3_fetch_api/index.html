Rick and Morty Character Search

Search for characters using the Rick and Morty Web API

About This Assignment

This web page uses JavaScript fetch() to retrieve character data from the Rick and Morty API. The user can search by character name and filter by species. The page then displays matching characters with their image, name, status, species, gender, and origin.

API Used: Rick and Morty API
